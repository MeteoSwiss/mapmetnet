# Getting Started

> [!WARNING]
> The `mapmetnet` package is under active development. You can expect regular breaking changes, poor
> documentation, and rapidly evolving APIs. If you want to use the package, please reach out to the
> developers and we will be happy to help you get started.

The `mapmetnet` package has 3 primary intended uses:

1. the assembly of meteorological **network maps**,
2. the computation of the **horizontal resolution** (in the [GBON](https://wmo.int/activities/global-basic-observing-network-gbon) sense) of a given network, and
3. the generation of **sat-view diagrams** for individual observing sites.

For instructions on how to install and use the mapmetnet package, please refer to the full
[documentation](https://meteoswiss.github.io/mapmetnet/).

Unexpected behavior and problems arising while using mapmetnet can be reported and tracked using
[GitHub issues](https://github.com/MeteoSwiss/mapmetnet/issues).

If you wish to contribute to the development of mapmetnet, please refer to the
[contributing guidelines](https://github.com/MeteoSwiss/mapmetnet/blob/main/CONTRIBUTING.md).
